# Карты PUBG RU

Интерактивный статический сайт с картами PUBG: метки объектов, координатная сетка,
измерение расстояния и планировщик линии полёта самолёта.

## Стек

- [React 19](https://react.dev) + [vinext](https://github.com/.../vinext) (Next.js-подобный
  маршрутизатор на базе Vite, RSC)
- TypeScript
- Статический экспорт, публикация на GitHub Pages из корневого пространства домена `pubg-maps.ru`

## Быстрый старт

Требуется Node.js >= 22.13.

```sh
npm install       # установить зависимости
npm run dev       # локальный dev-сервер (http://localhost:5173)
npm run build     # собрать статический экспорт
npm run test      # прогнать тесты (node --test)
npm run lint      # oxlint
npm run format    # oxfmt
```

## Структура

```
app/                    # приложение (layout + страница)
  page.tsx              # интерактивная страница с картой
  globals.css           # стили
lib/                    # чистая логика (без React)
  map-geometry.mjs      # координаты, сетка, выбор уровня тайлов
  marker-display.mjs    # подписи и группировка меток
  flight-plan.mjs       # расчёт линии полёта самолёта
data/                   # данные карт и меток
  maps.json             # список поддерживаемых карт
  markers.json          # типы меток, группы и координаты (источник ниже)
maps/                   # сгенерированные ассеты (обзор, превью, тайлы)
tools/
  build-quality-maps.mjs  # генерация ассетов из PNG-оригиналов
tests/                  # тесты (node --test)
```

## Источник данных

`data/markers.json` собирается с внешнего источника. В файле есть поле `updated` —
метка времени последней синхронизации. Подписи меток для UI задаются в
`lib/marker-display.mjs`, а не берутся дословно из данных: у источника
часто слишком общие названия («Транспорт 1», «Случайные лодки 2»).

Список карт, доступных в интерфейсе, лежит в `data/maps.json` (сейчас
поддерживаются 6 карт по 8 км: Эрангель, Мирамар, Викенди, Тэго, Дестон, Рондо).

## Обновление ассетов карт

Оригинальные PNG 8192×8192 хранятся вне репозитория (в родительской папке
проекта). Скрипт генерирует WebP-обзоры, превью и тайлы в `maps/`:

```sh
npm run maps:quality
```

> Ассеты лежат в корневом `maps/`, а не в `public/` — так статический экспорт
> публикует их прямо из корня. При переносе карт убедитесь, что пути в
> `page.tsx` (`./maps/...`) и в тесте `marker-scale-audit` не разъехались.

## Как добавить новую карту

1. Добавьте PNG-оригинал 8192×8192 в родительскую папку проекта.
2. Пропишите её в `maps` внутри `tools/build-quality-maps.mjs`.
3. Запустите `npm run maps:quality` — появятся файлы в `maps/`.
4. Добавьте запись в `data/maps.json`.
5. Для карт с другим размером сетки (не 8 км) дополнительно адаптируйте
   `markerPoint`/`markerCalibration` в `lib/map-geometry.mjs` и сетку в UI.
6. Обновите тесты (`marker-scale-audit`, `map-geometry`) под новую карту.

## Публикация

Сайт статический и публикуется из корня домена `pubg-maps.ru`
(см. `CNAME`). Соберите экспорт `npm run build` и разместите результат
в корне веб-пространства. Билд-артефакты (`index.html`, `_next/` и т.д.)
хранятся в репозитории и обновляются коммитами «Regenerate Vite build artifacts».
