# Карты PUBG RU

Интерактивные русскоязычные карты Эрангеля, Мирамара, Викенди, Тэго, Дестона и Рондо.

## Возможности

- плавное перемещение и масштабирование с загрузкой только нужных фрагментов карты;
- сетка 1 км, которая при приближении меняется на сетку 100 м;
- фильтруемые метки с пиктограммами;
- измерение расстояния между двумя точками.

## Данные

`public/data/maps.json` содержит параметры карт, а `public/data/markers.json` — категории и координаты меток. Карты рассчитаны на размер 8×8 км.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверка: `npm test` и `npm run build`.
