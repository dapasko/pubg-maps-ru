# Обновление меток — 17 октября 2026

Источник изменений: https://pubg.gs/changelog/. На момент проверки журнал
содержит изменения сборок 25225767 (10 сентября), 25449918 (23 сентября)
и 25901960 (14 октября). Свежие данные самого источника относятся к PUBG
43.2, Steam build **25976382**, извлечение 16 октября:
https://pubg.gs/about/. Версию журнала и версию текущих данных не смешиваем.

Всего **6364 метки**, включая **133 точки мотопланеров** вместо 118.
Координаты новых групп O/S взяты только из базового слоя без `mode`;
точки IBR к ним не примешаны. Преобразование сантиметров источника:
`[-y / extent * 256, x / extent * 256]`, `extent = 816000`.

Старые группы G мотопланеров заменены группами O/S; группа G
аэроглиссеров Дестона сохранена. Для Эрангеля удалена группа E, для
Мирамара — E/F. Основание удаления — не исчезновение координат:
кандидатные водные позиции ещё присутствуют в слоях источника, но
действующие правила не содержат для этих групп ни одного типа транспорта,
а таблицы `vehicleSpawns` не содержат Water/Water_Ferry.
Фиксированные лодки L сохранены: 23 точки Эрангеля и 10 Мирамара.

Список кандидатов не означает одновременное появление транспорта во всех
точках. Для O правила задают 4 спавна за матч, для S — 2; группы представлены
отдельно. Старый тег `!100%` у обычных мотопланеров снят. Вес строки таблицы
не трактуется как процент вероятности.

Растры всех шести карт имеют те же хеши версий, что в предыдущем снимке;
изображения не менялись. В сентябрьском журнале отмечена перестройка
Мирамара, но локальный растр уже соответствует актуальной версии
`ecc67e93`.

Удалённая водная опорная точка Эрангеля заменена на независимую точку
вышки синего чипа. Проверены её world-координаты, SHA-256 внешнего тайла
и соответствующего локального тайла; средняя разность RGB 0.801 из 255.

## Границы сверки и воспроизводимость

Числовые данные, таблицы транспорта, координаты O/S, URL и SHA-256
свежих слоёв сохранены в `data/game-update-2026-10-17.json`.
Общие веса транспорта и удаления специальных машин в журнале изучены;
у сайта нет отдельного справочника вероятностей или категории Pillar UAZ
Рондо, поэтому новые элементы интерфейса для них не добавлялись.
Изменения оружия, косметики, стартовых позиций и обычного лута также
не соответствуют существующим слоям сайта.

Остальные группы, включая исходные точки неизвестного режима, сохранены
без изменения. Поле `baseSourceUpdated` сохраняет исходную дату pubg.plus;
`partialUpdate` явно указывает область свежей сверки. Это не полная
сертификация всех 6364 объектов для текущей игры.

Снимок `marker-source-snapshot.json` и отчёт от 11 октября остаются
историческими: повторный запуск `markers:audit` сравнивает с тем старым
снимком, поэтому новые O/S не следует трактовать как ошибочные объекты.

Сайт получает `data/maps.json` и `data/markers.json` через fetch при открытии.
Для этой замены данных пересборка React-артефактов не требуется.

Проверки: `npm test`, `npm run test:browser` на локальном статическом
экспорте. Тест запуска CLI исправлен через `fileURLToPath`, чтобы работать
на Windows и в каталогах с кириллицей. Дополнительно проверено точное
соответствие 133 новых позиций исходным сантиметровым координатам,
сохранение остальных групп и SHA-256 файла меток в паспортах карт.

Результат: **31/31 Node-тест**, **30 сочетаний карт и масштаба**,
**31820 DOM-якорей**, **5 размеров экрана**, без pageerror. Браузерный
тест запускался с установленным Chrome через временный адаптер
`chromium.launch`, задающий `channel: 'chrome'`; дополнительный браузер
не требовался. Числовой отчёт: `2026-10-17-browser-alignment.json`.
Известное расхождение кончика SVG и DOM-якоря до 3.359 CSS px остаётся
прежним; эта замена данных его не исправляет. Проверка в реальном матче
не выполнялась.
