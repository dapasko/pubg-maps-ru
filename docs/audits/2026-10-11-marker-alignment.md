## Установленная ошибка и исправление

Ручная сентябрьская калибровка Эрангеля (`easting=-0.288`, `northing=0.288`) перемещала точки на −9.216 пикселя по каждой оси растра 8192×8192. На 12 независимо полученных опорных точках диагональная ошибка составляла 13.094–13.220 пикселя; медиана 13.156. Без неё максимальная ошибка — 0.187 пикселя. Удалена только эта калибровка. Исходные 6 550 координат и изображения не заменялись.

У остальных пяти карт исходные оси и масштаб совпадают с внешним преобразованием. Изменять их не потребовалось.

## Независимый эталон и версии

- PUBG Update 43.1, Steam build 25744443, дата извлечения 2026-10-07 — объявлены на https://pubg.gs/about/.
- Все шесть `/layers/*.json` возвращают `extent=816000` сантиметров. Клиент pubg.gs нормализует `x/extent`, `y/extent` и использует Leaflet CRS.Simple с рамкой `[0,0]..[-256,256]`.

Растр охватывает **8.16 км**, тогда как название карты и текущая модель расстояний интерфейса округлены до 8 км. Эта сверка не меняет модель расстояний/полёта.
- Данные сайта заявляют дату 2026-09-11; версия игрового билда и режим локального источника не объявлены. Открытая страница pubg.plus сейчас содержит клиент 2.4.6v8 (7eb07c7), 2026-10-06; это версия клиента, не доказанная версия наших меток.
- Сохранены числовые выдержки внешнего снимка, URL, SHA-256 исходных ответов и хеши тайлов. Полные ответы и изображения для исследования лежат в игнорируемом `work/source-audit/`.

## Поточечная сверка категорий и режимов

Сравнение один-к-одному с допуском **2 пикселя**, отдельно по категориям. Один внешний объект нельзя зачесть двум дублирующимся локальным точкам. «Совпадение» означает координаты объекта соответствующей категории, не гарантированное появление в конкретном матче. Пары ближе порога выбираются начиная с ближайшей; при неоднозначных дубликатах результат консервативен и не считается доказательством полноты набора.

| Карта | Совпало с базовой категорией | Совпало с IBR той же группы¹ | Совпало с IBR без группы¹ | Осталось несовпадений² | Без эквивалентной категории |
| --- | ---: | ---: | ---: | ---: | ---: |
| erangel | 878 | 48 | 84 | 4 | 293 |
| miramar | 756 | 15 | 107 | 17 | 456 |
| vikendi | 610 | 24 | 85 | 21 | 639 |
| taego | 489 | 0 | 0 | 0 | 92 |
| deston | 665 | 11 | 97 | 9 | 595 |
| rondo | 407 | 4 | 44 | 3 | 97 |

¹ Это дополнительные свидетельства координат: локальный режим неизвестен, поэтому точки **не помечены как проверенные для IBR или Normal**. Не сгруппированные внешние точки не получают придуманную группу транспорта.

² После отдельного учёта свидетельств IBR; не доказанные «лишние» или «перемещённые» объекты.

**Итого:** 3 805 совпадений в сопоставимых базовых категориях, ещё 519 совпадений координат с отдельными данными IBR, 54 несовпадения в сопоставленных категориях и 2 172 точки без установленной внешней эквивалентной категории. Сумма — все 6 550 точек.

Полный машинный отчёт: [2026-10-11-marker-alignment.json](2026-10-11-marker-alignment.json). Он содержит индексы и координаты локальных несовпадений, ближайшие внешние точки, внешние несовпадения, режимы и отсутствующие группы. Это отчёт различий, не автоматический список удаления/добавления.

Примечательные результаты:

- Все 171 локальная башня совпадают с внешними координатами. На Тэго внешние данные содержат ещё 34 башни, но локальной категории нет; импорт не выполнен.
- `brokenPotSpawner`: Эрангель 132/132, Мирамар 186/186, Викенди 108/108. На Дестоне 202/203; оставшаяся точка имеет ближайший внешний объект примерно в 7.03 пикселя. Близость не доказывает, что это один объект.
- Все 30 точек `bearCaves` Викенди совпадают с `BP_BearSpawnStart_C`. Это координаты спавна медведя, не проверка геометрии каждого входа пещеры.
- Транспортная группа A в локальных данных содержит точки, совпадающие и с базовыми, и с IBR-слоями. Сравнение прежних суммарных чисел без режима вводило в заблуждение.
- На Дестоне у внешнего источника есть пять базовых точек группы L, которой нет в локальном наборе. Это требование проверки категории/версии, не команда добавить точки.
- Тайные комнаты (134 точки), crowbarRooms, автоматы, канистры, заправки и часть групп транспорта остаются без установленного эквивалентного внешнего слоя. Автоматы `vending` pubg.gs находятся в других подуровнях (`SLB_*`); их нельзя подменять категорией `cVendingMachine`. `supplyBoxes` внешнего источника помечены IBR, не эквивалентны 117 локальным ящикам Викенди.

## Воспроизводимость и проверки

```sh
npm install
npm run markers:audit -- --output work/marker-alignment.json
npm test
npm run build
npm run lint
npx oxlint app lib tools tests
npx playwright install chromium
npm run dev -- --port 5173
# В другом терминале:
npm run test:browser
```

- Новый тест сначала воспроизвёл ошибку Эрангеля: 13.110 px > 2 px; после удаления калибровки прошёл. Дополнительно проверяются контрольные суммы тайлов, сохранность исходных координат эталонов, дубликаты и пустые/невалидные наборы.
- 31 Node-тест прошёл, сборка прошла. Исходный `npm run lint` завершился без ошибок, но выдаёт 1 156 предупреждений в уже сохранённых `_next/` артефактах. Проверка исходников `npx oxlint app lib tools tests` прошла без предупреждений.
- Chromium: 30 сочетаний шести карт и масштабов 100/200/400/800/1200%; проверено 32 750 DOM-якорей, переключение уровней тайлов, 72 независимых эталона на каждом масштабе, отсутствие pageerror. Дополнительно карта остаётся квадратной в пяти размерах 320×844, 390×844, 768×1024, 1024×1000, 1440×1000. Это проверка эмуляции браузера, не физических телефонов.

## Что ещё не закрыто

Этап 1 **не объявлен полностью завершённым**: требуется независимый эталон для отсутствующих категорий, уточнение режима/версии локальных данных, разбор 54 несовпадений и первоначальная версия трёх старых растров. Сетевой блок больше не является причиной остановки.

Этап 2: реальный SVG-кончик сейчас отстоит от DOM-якоря до **3.359 CSS px** при большом масштабе. Браузерная проверка фиксирует этот дефект отдельно; удаление калибровки координат не исправляет поля SVG. До коррекции SVG-якоря нельзя утверждать, что все видимые кончики точны с допуском ≤1 CSS px.

Также нужно отдельно привести расстояния и сетку к подтверждённому размеру 8.16 км: текущие расчёты используют номинальные 8 км (ошибка масштаба около 2%). Это влияет на измерения/планировщик, а не на нормализованные позиции меток.

Изменения подготовлены в ветке `audit/marker-alignment`; публикация и проверка публичного сайта не выполнялись.
